# Сквозь травы

Русскоязычный одностраничный редакционный сайт о Наталье Семёновой и текстильных работах, экспонировавшихся в РГБМ. Подлинное интервью из семи вопросов, документальные фотографии и декоративные ленты из предоставленного PNG. Публикация настроена через GitHub Pages; публичный адрес указан ниже.

## Запуск

Node.js 22.12+; проверено на Node.js 24.19.0.

```sh
cd /workspace/instalation
npm ci
npm run dev
```

`npm run build` создаёт `dist/`; `npm run preview` позволяет проверить сборку. Для размещения достаточно содержимого `dist/`. Внешние API, учётная запись Google и секреты для работы сайта не нужны: изображения и шрифты локальные.

## Замена контента

`src/content.js` содержит все вопросы, ответы и данные изображений:

- `interview`: главы, подлинные `question`, массив абзацев `paragraphs`. Разметка генерируется через `textContent`, без вставки HTML из источников.
- `media`: `src`, `srcset`, `large`, размеры, содержательный `alt`, подпись `location`, авторство `credit`. Не менять локацию на РГБМ для фотографий в другом пространстве.
- `textile.src`: прозрачная декоративная графика. Это рисунок из исходного PNG, а не фотография произведения.

Файлы находятся в `public/materials/`. Все фотографии показываются целиком через `object-fit: contain`, без изменения пропорций. Клик открывает увеличенную версию с Escape и возвратом фокуса. При `src: null` или ошибке загрузки появляется явно обозначенный пропуск; сейчас все восемь фотографий подключены.

## Проверенные источники

Оригиналы изучены и сохранены вне checkout: `/workspace/installation-source-materials`.

- `Интервью.docx`: все семь вопросов и полные ответы. Убраны служебные временные метки переписки, исправлены единичные опечатки и пунктуация, длинные ответы разделены на абзацы. Новые реплики не добавлялись.
- `Инсталяция в художке.pdf`: одна страница, подтверждает размеры, даты создания и техники. Название оранжевой работы расходится в заголовке и тексте PDF.
- `photo_5408949193042237068_y.jpg`: общий вид экспозиции в РГБМ; обе работы видны в библиотечном пространстве.
- `IMG_4240.HEIC`: монтаж в РГБМ; личность человека на фото не устанавливалась.
- `Фото/`: просмотрены все девять файлов — три общих вида «Трав», четыре крупные детали, два снимка оранжевой работы. Точная локация этой съёмки не подтверждена и не обозначена как РГБМ.

Происхождение опубликованных изображений перечислено в `public/materials/provenance.json`. Использованы только уменьшение и перевод в WebP; без ретуши, генерации или обрезки фотографий. Оригинальные документы с временными метками не включены в публичную сборку.

## Оформление и движение

Prata + Golos Text с кириллицей, локальные шрифты с OFL-лицензиями. Изумрудный `#006054` взят из фото плетения, коралловый `#e46054` — из фото оранжевой работы. Для текста коралловый затемнён до `#b14336`.

Нативный вертикальный scroll, без перехвата колеса или касаний. Три приёма: расхождение краевых PNG на первом экране; смещение декоративного слоя до 18 px; переход от общего вида к детали через clip-path в центральной sticky-главе. На телефоне оба центральных фото идут последовательно, sticky отключён. При `prefers-reduced-motion` отключены перемещения и sticky, весь материал доступен. Автоматического звука нет.

Уточнить окончательное название «Воспоминание в оранжевом цвете» / «Воспоминание в оранжевом цвете / Солнце»; даты экспонирования; авторов интервью, фотографий, рисунка и редакционных материалов; права на публикацию; локацию отдельной съёмки на белых стенах. Даты переписки не считать датами выставки. «Сквозь травы» — рабочее название сайта, не подтверждённое название выставки.

Оформление описано в `DESIGN.md`. Применены инструкции официального Impeccable 4.8.0: launcher engine отсутствует, использован документированный fallback с прямым чтением инструкций и независимой визуальной проверкой. Настройки облачной среды повторно не менялись. Публикация GitHub Pages выполняется отдельно, после явного согласия пользователя.


## Просмотр через GitHub Pages

Публичный адрес: https://daniillevites-web.github.io/instalation/dist/

Корень https://daniillevites-web.github.io/instalation/ перенаправляет на лендинг. В настройках Pages выбран GitHub Actions. Workflow `.github/workflows/pages.yml` устанавливает зависимости по lockfile, собирает сайт и публикует артефакт с каталогом `dist` и корневым перенаправлением. Изменения в `main` запускают следующую публикацию; доступен и ручной workflow_dispatch. Ветка с исходниками не содержит сгенерированный `dist`.

Сборка настроена с относительным `base: './'`; изображения в `src/content.js` тоже имеют относительные пути. Проверено обслуживание по вложенному адресу `/instalation/dist/`: загружаются все фотографии, шрифты, JavaScript, CSS и увеличенные изображения.

Статус сборок: https://github.com/daniillevites-web/instalation/actions

Существующий сайт `mezdu_knig` не изменяется этим workflow.
